# Photos

Drop real session photos here with these exact names and they'll appear automatically
in the "On the water" gallery — no code changes needed:

```
ride-1.jpg   ride-2.jpg   ride-3.jpg
ride-4.jpg   ride-5.jpg   ride-6.jpg
```

Until a file exists, that tile shows a soft gradient with a camera icon (a "photo goes
here" placeholder). As soon as the JPG loads, the icon disappears and the photo fills the
tile. The caption under each tile is set in `index.html` (the `<figcaption>` in the
`.gallery` section) — edit those to match your photos.

**Good sources for these:** your own photos from the boat, or the ones on the
[AWS Facebook page](https://www.facebook.com/297AWS) (you own those).

**Don't** copy other people's photos from Tripadvisor reviews — those belong to the
travellers who took them and Tripadvisor's terms don't allow reusing them on the site.
The live Facebook feed and the review quotes already bring that content in properly.

Recommended: landscape (4:3 or wider), at least 1200px on the long edge, JPG, compressed
to ~200–400 KB each.

Optional: add `hero.jpg` here and see the note in the project README about using it as a
hero background.
